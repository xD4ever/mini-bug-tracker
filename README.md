# BugBoard

Mini bug-tracker construit avec Vue 3, TypeScript, Vite et Vue Router. L'application consomme l'API REST sur `/api/tickets` et couvre la consultation, la recherche, la création, la mise à jour et la suppression des tickets.

## Installation et lancement

```sh
npm install
npm run dev
```

Pour utiliser une URL d'API différente, créer un fichier `.env` avec `VITE_API_URL`.

```sh
npm run build
```
